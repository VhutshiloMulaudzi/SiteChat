02 / Installation

Add one script.

Put this snippet in the page where you want SiteChat to appear. No inline JavaScript is needed for a standard installation.

sitechat.html

//

Content security policy

Allow the SiteChat host in script-src, style-src, and font-src, plus connect-src for chat requests. Origins must still be allowlisted on the server.

  1. 01

    Host the backend over HTTPS. Point the script at the same SiteChat host that serves your chat endpoint.

  2. 02

    Allowlist your own domains. Configure provider credentials on the server—never in browser code.

  3. 03

    Test the real page. Verify the allowed origin and CSP before publishing the embed.

03 / Production notes

Keep the boundary clear.

Origins are not identity

Domain allowlisting limits where the widget can call from; it is not authentication or a substitute for protecting your API.

Keep sensitive data out

Do not send secrets or sensitive information through a general website chat. Browser-delivered configuration should not contain provider keys.

Bring your own knowledge

SiteChat does not crawl your site. Knowledge and prompt configuration belong in your server-side setup and can be changed there.
